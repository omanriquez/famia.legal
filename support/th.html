คำถามที่พบบ่อย

การซิงค์ iCloud ทำงานอย่างไร?

Famia ใช้ iCloud เพื่อซิงค์ข้อมูลของคุณโดยอัตโนมัติในอุปกรณ์ Apple ทั้งหมดของคุณ ตรวจสอบให้แน่ใจว่า iCloud เปิดใช้งานบนอุปกรณ์ของคุณและคุณลงชื่อเข้าใช้ด้วย Apple ID

ฉันสามารถเพิ่มสมาชิกได้กี่คน?

Famia รวมทุกฟีเจอร์ คุณสามารถเพิ่มสมาชิกในครอบครัวได้ตามที่ต้องการ โดยไม่มีขีดจำกัด

ฉันจะเปิดใช้งาน Face ID/Touch ID ได้อย่างไร?

ไปที่การตั้งค่าในแอปและเปิดใช้งาน "การตรวจสอบสิทธิ์ทางชีวภาพ" สิ่งนี้จะปกป้องข้อมูลครอบครัวของคุณด้วย Face ID หรือ Touch ID

ฉันสามารถส่งออกข้อมูลของฉันได้หรือไม่?

ได้ คุณสามารถส่งออกข้อมูลทั้งหมดของคุณจากส่วนการตั้งค่า ข้อมูลจะถูกส่งออกในรูปแบบ PDF

ข้อมูลของฉันปลอดภัยหรือไม่?

แน่นอน ข้อมูลทั้งหมดของคุณจะถูกเก็บไว้เฉพาะในอุปกรณ์ของคุณและใน iCloud ส่วนตัวของคุณ Famia ไม่สามารถเข้าถึงข้อมูลของคุณและเราไม่แบ่งปันกับบุคคลที่สาม

Famia มีการสมัครสมาชิกหรือไม่?

ไม่มี. Famia มีราคา 9.99 ดอลลาร์สหรัฐเมื่อดาวน์โหลด และรวมทุกฟีเจอร์ หากคุณสมัคร Famia Pro ไว้ก่อนหน้า Apple จะเรียกเก็บการสมัครนั้นต่อไปจนกว่าคุณจะยกเลิกในการตั้งค่าของ iPhone ใต้ Apple ID ของคุณ ในส่วนการสมัครรับ

ฉันสามารถใช้ Famia บน iPad และ iPhone ได้หรือไม่?

ได้ Famia ได้รับการปรับให้เหมาะสมสำหรับ iPhone, iPad และ Mac (Catalyst) ข้อมูลของคุณจะซิงค์โดยอัตโนมัติในอุปกรณ์ทั้งหมดของคุณ

การแก้ไขปัญหา

การซิงค์ไม่ทำงาน

  • ตรวจสอบว่า iCloud เปิดใช้งานในการตั้งค่า → [ชื่อของคุณ] → iCloud
  • ตรวจสอบให้แน่ใจว่าคุณมีการเชื่อมต่ออินเทอร์เน็ต
  • ตรวจสอบว่าคุณมีพื้นที่จัดเก็บ iCloud ว่าง
  • ลองปิดและเปิดแอปอีกครั้ง

แอปปิดโดยไม่คาดคิด

  • ตรวจสอบให้แน่ใจว่าคุณติดตั้ง iOS เวอร์ชันล่าสุดแล้ว
  • อัปเดต Famia เป็นเวอร์ชันล่าสุดที่มีอยู่
  • รีสตาร์ทอุปกรณ์ของคุณ
  • หากปัญหายังคงอยู่ ติดต่อฝ่ายสนับสนุน

ฉันยังเห็นการเรียกเก็บเงิน Famia Pro

  • เปิดการตั้งค่าบน iPhone แล้วไปที่ Apple ID ของคุณ ส่วนการสมัครรับ
  • ยกเลิก Famia Pro แอปมีทุกฟีเจอร์อยู่แล้ว
  • ใช้ Apple ID เดียวกันกับที่ใช้สมัคร

รายงานปัญหา

หากคุณพบข้อบกพร่องหรือมีข้อเสนอแนะ เรายินดีรับฟังจากคุณ ข้อเสนอแนะของคุณช่วยให้เราปรับปรุง Famia

💡 เมื่อรายงานปัญหา ให้รวม:

  • เวอร์ชัน iOS ที่คุณใช้
  • รุ่นอุปกรณ์ (iPhone 15, iPad Pro ฯลฯ)
  • คำอธิบายโดยละเอียดของปัญหา
  • ขั้นตอนในการทำซ้ำข้อผิดพลาด
  • ภาพหน้าจอถ้าเป็นไปได้
